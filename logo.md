# System Appointment — Logo Assets

SVGs vetoriais reconstruídos com base na identidade visual aprovada.

- `icon-gradient.svg`: símbolo principal, fundo transparente.
- `icon-navy.svg`, `icon-white.svg`, `icon-slate.svg`, `icon-sea.svg`: variantes monocromáticas.
- `logo-horizontal-light.svg` e `logo-horizontal-dark.svg`: assinaturas horizontais.
- `logo-vertical-light.svg` e `logo-vertical-dark.svg`: assinaturas verticais.
- `logo-horizontal-monochrome-*.svg`: versões de uma cor.
- `app-*.svg`: ícones com fundos de aplicação.

Cores: Navy #321E48, Slate Blue #43637E, Sea #65DCD5, Mint #D9FFF4.

Nota: são redesenhos vetoriais, não uma vetorização exata pixel a pixel da imagem raster original. O texto utiliza Inter com fallback Arial; para distribuição totalmente independente de fontes, converta o texto em curvas em um editor vetorial.
